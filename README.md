1. Project Title

# Contact Manager

2. Description

- A simple and practical Python Contact Manager that allows users to manage their contacts using a command-line interface.

- The application stores contacts in a JSON file and supports adding, searching, editing, deleting, and sorting contacts.

3. Features

- Add a new contact
- Search for a contact
- Delete a contact
- Edit a contact
- Show contacts
- Sort contacts by name
- Sort contacts by phone number
- Validate names and phone numbers
- Save contacts automatically in a JSON file
- Load contacts automatically when the program starts
- Prevent duplicate contacts

4. Technologies

- Python
- JSON
- PyCharm

5. How to Run 

##
- Download or clone the project.
- Open the project in PyCharm.
- Make sure Python is installed.
- Run `main.py`.
- Use the menu to manage your contacts.
